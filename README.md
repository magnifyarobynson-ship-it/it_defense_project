# ✅ Task Manager — IT Project

A simple full-stack Task/To-Do Manager web app built with **HTML, CSS, JavaScript, Node.js, Express and MongoDB**.

## 🖥️ Live Demo
🔗 [View on GitHub Pages](https://magnifyarobynson-ship-it.github.io/it_defense_project)

## 📋 Features
- Add, view, edit and delete tasks
- Set priority (Low / Medium / High) and due dates
- Mark tasks as complete / reopen them
- Filter and search tasks
- Fully connected to MongoDB Atlas cloud database

## 🗂️ Screens
| Screen | Description |
|--------|-------------|
| Dashboard | Summary cards + recent tasks |
| Add Task | Form to create a new task |
| All Tasks | Full list with search & filter |
| Task Detail | View, edit, complete a task |
| Completed | Archive of finished tasks |

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Hosting:** GitHub Pages (frontend) + Render (backend)

## 🚀 Run Locally
```bash
# Install dependencies
npm install

# Add your .env file
MONGO_URI=your_mongodb_atlas_uri
PORT=5000

# Start server
npm run dev
```

Then open http://localhost:5000
